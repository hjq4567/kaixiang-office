# 反馈表先查数据，再解释数字

先确认数据是问卷还是别的记录、哪列是评分、评分范围、单选还是多选。用户已给定就直接使用；未给范围不能看到9分便断定无效。

对明确评分范围的CSV，可运行同目录上一级的 scripts/feedback_check.py。仅需Python 3标准库，不用安装pandas。下列参数中的列名、路径和评分范围须来自本次任务：

```text
python "<技能目录>/scripts/feedback_check.py" "<输入.csv>" --score-column "满意度" --minimum 1 --maximum 5 --id-column "记录号" --single-choice-column "想学内容" --out "<新的结果目录>"
```

该程序保留全部原始行，分别列出空白、非数字、非有限数和超范围评分；只对范围内数值计算有效评分平均值，同时保留未排除超范围值的原始数值统计。它不替你决定量表，也不修表。重复记录号只提醒，不自动去重；在用户确认其含义前，结果按原始行计算。结构不齐的CSV拒绝计算，而不是悄悄丢行。

选项统计仅支持一个单选列，选项去掉首尾空格后计数，区分“占全部记录”与“占有填写该选项的记录”。多选题、分号拼接、别名合并、跨表匹配、Excel公式都不能冒充本程序已支持。评分是否有效与该行单选回答是否填写是两个问题，不互相删行。

缺Python或附件不是CSV时，可用实际可用工具另做核对；如实说明替代方法。没有参训总人数等基数，不算问卷回收率；样本里的相关现象不写成因果结论。


显示数字时优先用score.valid_mean_rounded（两位）与选项percent_rounded（of_all_records、of_nonempty各一位）；原始高精度数仍保留，null不写成0。

出现疑似多选拼接字符时，程序会提醒“疑似多选题，本程序只按整串统计，未拆分”；其中斜线也可能是正常名称，不能自动认定多选。先向用户确认，不直接抄整串占比当每个选项占比。

无法按UTF-8读取时会提示 --encoding gbk；制表符表格可显式加 --delimiter tab，分号分隔文件可加 --delimiter semicolon。不要无声猜编码或分隔符，也不修改原文件。

## 产物骨架

### 章节

未指定模板时按以下顺序，用户模板优先。

1. 一、数据范围：文件、条数、评分范围、题型和计算方式。
2. 二、评分与异常：有效条数、合计、两位平均分，空白和异常分列。
3. 三、选项占比：次数、分母、一位小数占比，疑似多选先提醒。
4. 四、待确认事项：重复记录、题型及未给出的基数。

### 约定

- 另交feedback_report.json与score_rows.csv，中文数字能够回查。
- 新增分析放在“待确认事项”之前并说明用途；用户指定格式优先。
